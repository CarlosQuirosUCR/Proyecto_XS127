# Proyecto_XS127
Análisis y comparación de modelos de pronóstico para la serie mensual de consumo de gas natural residencial en Estados Unidos durante el período 1973–2026. Se emplean métodos de suavizamiento exponencial, regresión, ARIMA/SARIMA y regresión dinámica para evaluar su capacidad predictiva y seleccionar el modelo más adecuado.
